A one-line excuse from a home Wi-Fi router for dropping the connection at the exact climax of a movie — written by a tiny TypeScript program for the [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) bounty on make.fun.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the single-line entry to `output/entry.txt` (no trailing newline).
